# AGENTS.md

## Project goal

Maintain a fast, modern and professional portfolio for Abdias Peguero, focused on Lead/Senior Data Engineering opportunities.

## Technical constraints

- Use semantic HTML, modern CSS and vanilla JavaScript.
- Keep the site deployable as static files.
- Do not add paid services.
- Avoid dependencies unless they provide a clear, substantial benefit.
- Preserve responsive behavior and accessibility.
- Never publish confidential employer data, internal table names, credentials or proprietary architecture details.

## Design direction

- Modern technological visual style
- Dark background with cyan, blue and violet accents
- Strong typography and generous spacing
- Subtle motion that respects `prefers-reduced-motion`
- Clear project outcomes and measurable business impact

## Quality checklist

Before completing a change:

1. Verify navigation and links.
2. Check mobile layout at approximately 375px width.
3. Check desktop layout at 1440px width.
4. Preserve keyboard accessibility.
5. Avoid horizontal scrolling.
6. Keep content truthful and professionally phrased.
7. Ensure no secrets or personal contact details are committed accidentally.

## Main files

- `index.html`: content and page structure
- `assets/styles.css`: visual system and responsive layout
- `assets/script.js`: menu and reveal animations
